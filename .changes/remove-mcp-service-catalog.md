- The MCP service catalog is gone: the daemon no longer ships or serves a compiled catalog of services, its catalog browsing and search surfaces are removed, and `/mcp` plus `pa mcp list` show only the servers configured in `mcpServers` and the built-in integrations. Generic MCP tools, `mcp.begin_login`, and OAuth login keep working, and `mcpCatalogSources` is no longer a setting. The kernel `mcp` module drops `list_connections`, `list_plugins`, and `search_plugins`; `mcp.search_tools` now searches one named connection.
